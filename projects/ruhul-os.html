Ruhul OS

Portofolio yang dibuat seperti meja kerja: map, berkas, sticky note, dan kupu-kupu kertas di atas cutting mat. Dibangun tanpa framework supaya ringan dan mudah dirawat.

Peran
Desain, pengembangan, pengujian
Tahun
2026
Teknologi
HTML, CSS, JavaScript, GSAP
Bantuan AI
Claude untuk refactor dan review kode

Masalah

Portofolio developer biasanya terlihat sama: daftar skill, grid kartu, tombol kontak. Saya ingin pengunjung penasaran dan mau menjelajah, tanpa mengorbankan kecepatan dan aksesibilitas.

Proses

  • Menentukan satu tema, meja kerja di atas cutting mat, supaya setiap bagian terasa satu dunia.
  • Mengumpulkan objek meja nyata (pensil, selotip, klip, sketchbook) sebagai aset berlapis.
  • Menulis HTML semantik dan CSS tanpa framework, lalu menambahkan GSAP untuk smooth scroll, pin, dan animasi per bagian.
  • Menguji di desktop dan mobile, termasuk mode reduced motion yang mematikan semua animasi.

Hasil

Situs statis tanpa build step yang bisa langsung di-host di GitHub Pages, dan tetap berfungsi penuh walau animasi dimatikan.
